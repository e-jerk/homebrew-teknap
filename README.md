# e-jerk/teknap tap

Homebrew tap for [TekNap 2](https://github.com/e-jerk/teknap).

```bash
brew trust --tap e-jerk/teknap
brew tap e-jerk/teknap
brew install teknap
teknap -v
```

Homebrew 6 requires `brew trust` before it will load a third-party tap.

Each TekNap `v*.*.*` release updates this formula (version + bottle SHA). The hourly sync is only a backup.
